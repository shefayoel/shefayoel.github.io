# שפע יואל - דפי השפות וההצטרפות
- `/` - דף ההצטרפות (כפתור "הצטרפו לערוץ", מהגיליון "הגדרות" > "קישור הערוץ").
- `/y/{מספר}` - ההודעה ביידיש לפי המספר הרץ שלה (1 עד 2000), `/e/{מספר}` - באנגלית. מופיעה רק אחרי "פורסם".
